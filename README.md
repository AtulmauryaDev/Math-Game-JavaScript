# ?? Maths Game

A simple and interactive browser-based maths game built using HTML, CSS, and JavaScript. Test your multiplication skills by solving randomly generated questions before the timer runs out!

## ? Features

- **Random Multiplication Questions:** Solve multiplication questions using randomly generated numbers.
- **Four Answer Options:** Choose the correct answer from four options.
- **Score Tracking:** Earn one point for each correct answer.
- **60-Second Countdown:** Answer as many questions as possible within 60 seconds.
- **Instant Feedback:** Get visual feedback for correct and incorrect answers.
- **Start and Reset:** Start a new game or reset the current game.
- **Simple User Interface:** Clean layout with interactive answer boxes.

## ?? How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `Index.html` in your web browser.
4. Click **Start Game** to begin.
5. Select the correct answer from the four available options.
6. Try to achieve the highest score before the 60-second timer ends.

No backend server or database is required.

## ?? How to Play

1. Click **Start Game**.
2. A multiplication question will appear.
3. Select one of the four answer choices.
4. Correct answers increase your score by one point.
5. Incorrect answers display a retry message.
6. The game ends when the countdown reaches zero.
